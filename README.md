# @osumi/ticketbaiws

SDK TypeScript universal para la API de TicketBaiWS de Berein.

Compatible con entornos que implementen las APIs Web estándar necesarias, como Node.js y aplicaciones web.

## Estado

El proyecto se encuentra actualmente en desarrollo.

Las versiones `0.x.x` pueden introducir cambios incompatibles hasta alcanzar la primera versión estable `1.0.0`.

## TicketBaiWS

TicketBaiWS es un servicio de Berein que permite gestionar la comunicación con TicketBAI y Verifactu mediante una API REST.

Esta librería no implementa TicketBAI ni Verifactu directamente. Actúa como cliente de la API de TicketBaiWS.
